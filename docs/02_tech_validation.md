**검증일**: 2025-02-09

## 1. 테스트 환경

- Python 3.13.11
- macOS Darwin 24.6.0
- 의존성: shazamio, yt-dlp, requests, ffmpeg

## 2. 음악 인식 (shazamio)

### 테스트 방법
YouTube 오디오 → MP3 추출 → shazamio 인식

### 테스트 결과
| 테스트 곡 | 결과 |
|----------|------|
| ROSÉ & Bruno Mars - APT. | ✅ 정확히 인식 |

### 결론
- **shazamio 사용 가능 확인**
- YouTube/파일 오디오에서 정확한 인식
- 곡 제목, 아티스트, 장르, Shazam Key 반환

---

## 3. 싱크 가사 조회 (LRCLIB)

### API 정보
- 엔드포인트: `https://lrclib.net/api/search`
- 인증: 불필요
- 포맷: LRC (타임스탬프 10ms 정밀도)

### 테스트 결과
```
[00:00.35] 채영이가 좋아하는 랜덤 게임, 랜덤 게임
[00:05.00] Game start
[00:06.62] 아파트, 아파트, 아파트, 아파트
...
```

### 결론
- **LRCLIB API 정상 작동**
- 싱크 가사 (LRC 포맷) 제공
- 한국어/영어 혼합 곡 지원
