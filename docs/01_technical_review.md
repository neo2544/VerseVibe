# VerseVibe 기술 검토 보고서

## 1. 가사 저작권 (라이선스) 검토

### 핵심 요약
개인 사용 목적이라면 법적 리스크는 매우 낮지만, 가사 자체는 저작권 보호 대상이다.

### 가사의 저작권 현황
- 가사(lyrics)는 문학 저작물로 저작권법의 보호를 받음
- 가사를 화면에 표시하는 것은 graphic rights에 해당
- 상업적 노래방 서비스는 동기화 라이선스 + graphic rights 필요
- 2025년 12월 독일 법원은 OpenAI의 무허가 가사 재현에 저작권 침해 판결

### 개인 사용 시 법적 판단

| 구분 | 리스크 | 비고 |
|------|--------|------|
| 개인 사용 (비공개, 비상업) | 매우 낮음 | Fair Use 범위 내 |
| 오픈소스로 공개 (코드만) | 낮음 | 가사 데이터 미포함 시 |
| 가사 DB를 직접 구축/배포 | 높음 | 저작권 침해 소지 |
| 상업적 서비스 운영 | 매우 높음 | 라이선스 필수 |

### 권장 방향
- 외부 API를 통해 가사를 실시간으로 가져오되, 로컬에 저장/재배포하지 않으면 안전
- LRCLIB 같은 커뮤니티 기반 무료 API 활용 (비상업 목적)
- 가사를 앱에 하드코딩하거나 DB로 번들링하지 말 것

## 2. 노래 인식 -> 가사 매칭 기술 방안

핵심 파이프라인: 음악 인식 -> 곡 정보 획득 -> 싱크 가사 조회 -> 실시간 표시

### Step 1: 음악 인식 (Song Recognition)

| 서비스 | 무료 여부 | 특징 |
|--------|-----------|------|
| Shazam API (비공식) | 무료 | 오픈소스 라이브러리 shazamio (Python) |
| ACRCloud | 프리티어 있음 | 1.5억곡 DB, 개발용 제한적 무료 |
| AudD | 유료 ($5/1000건) | 신경망 기반 오디오 핑거프린팅 |

추천: shazamio (Python) - 무료로 Shazam 내부 API 사용 가능

### Step 2: 싱크 가사 조회 (Synced Lyrics)

| 서비스 | 무료 여부 | 싱크 지원 | 특징 |
|--------|-----------|-----------|------|
| LRCLIB | 완전 무료 | LRC 포맷 | 300만곡+, API 키 불필요 |
| Musixmatch | 제한적 | Line + Word 싱크 | 가장 방대한 DB |
| Spotify Lyrics | 비공식 | Line 싱크 | sp_dc 쿠키 필요, TOS 위반 소지 |
| Netease | 무료 | LRC 포맷 | 중국/아시아 곡에 강함 |
| Genius | 무료 API | 싱크 없음 | 가사만 제공 |

추천: LRCLIB (1순위) + Netease (한국 곡 보완)

### Step 3: 가사 싱크 포맷 (LRC)

LRC 포맷 예시:
```
[00:12.00] 첫 번째 가사 라인
[00:17.20] 두 번째 가사 라인
[00:21.10] 세 번째 가사 라인
```

타임스탬프 기반으로 현재 재생 시점에 맞는 가사를 하이라이트

---

## 3. 추천 아키텍처

```
마이크 입력
  -> 음악 인식 (shazamio)
  -> 곡 정보 (제목, 아티스트)
  -> 싱크 가사 조회 (LRCLIB / Netease)
  -> LRC 파싱
  -> UI 실시간 표시
```

### 유용한 오픈소스 라이브러리

| 라이브러리 | 언어 | 용도 |
|-----------|------|------|
| shazamio | Python | Shazam 음악 인식 |
| syncedlyrics | Python | 여러 소스에서 싱크 가사 통합 검색 |
| @stef-0012/synclyrics | Node.js | Musixmatch + LRCLIB + Netease 통합 |

## 4. 한국 노래 가사 지원 현황

| 소스 | 한국 곡 지원 | 비고 |
|------|-------------|------|
| LRCLIB | 보통 | 인기곡 위주, 커뮤니티 기여 기반 |
| Musixmatch | 양호 | 한국 곡 커버리지 넓음 |
| Netease | 양호 | K-POP 커버리지 좋음 |

한국 곡 전략: LRCLIB -> Musixmatch -> Netease 순으로 폴백 검색

## 5. 결론

- 라이선스: 개인 사용 + API 실시간 조회 방식이면 법적 리스크 최소
- 기술적 실현 가능성: 충분히 가능. 오픈소스 도구 잘 갖추어져 있음
- 핵심 과제: 음악 인식 정확도와 한국 곡 싱크 가사 커버리지
